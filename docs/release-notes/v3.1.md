## 🚀 What's New in v3.1

### 🐛 Fixes
* **Breezy Weather Updates Reach the Widget**: Weather data broadcast by Breezy Weather is now stored and shown on the widget.
* **Keep Alive on Android 14+**: Enabling Keep Alive now asks for the Physical activity permission it needs, and turns itself back off with an explanation if the permission is denied, instead of failing silently.
* **Accurate Screen Time**: Screen time is now counted from exact app usage since local midnight, and time spent on the home screen is no longer included.

### ⚡ Performance & Battery
* **Lighter Partial Updates**: Calendar, tasks, alarm and step updates no longer fetch weather data they do not use.
* **Cleaner Manifest**: Removed broadcast actions that never reach the app, so the widget is not woken up for nothing.

### 🌐 Localization
* **Missing Translations Fixed**: "Today", "Tomorrow" and other labels that were still in English (for example in Russian) are now translated in all languages.
* **Settings Search in Your Language**: Searching settings now matches the translated card titles and descriptions.
* **Localized "No title"**: Calendar events and tasks without a title show a translated placeholder.
* **Stronger String Checks**: The CI string check now also catches untranslated copies of English text, unused strings and hardcoded English in code.
