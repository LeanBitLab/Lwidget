## 🚀 What's New in v2.9

### 🛡️ 100% Reproducible F-Droid Binary Verification
* **Stripped Dependency Metadata**: Explicitly disabled Android Gradle Plugin's proprietary dependency metadata signing block (`includeInApk = false`, `includeInBundle = false`). This eliminates the proprietary signing block (ID `0x504B4453`) that caused `fdroid scanner` failures during reproducible binary verification on F-Droid CI.
* **Fully Auditable & Open**: Guarantees bit-for-bit reproducibility between official GitHub releases and binaries built independently from source.

### ⚡ R8 Code & Resource Shrinking Hardening
* **Dedicated ProGuard Rules**: Added comprehensive keep rules in `proguard-rules.pro` for Kotlinx Serialization (`@Serializable` models and companion serializers in `com.leanbitlab.lwidget.weather`), Android AppWidget providers, and background services.
* **Preserved Dynamic Contracts**: Ensures aggressive R8 optimization and resource shrinking safely discard unused code while protecting all active widget entry points, intent filters, and JSON serialization.

### 🚀 Performance & IPC Optimizations
* **Singleton Weather Serializer**: Cached the `Json` parser instance as a singleton within `BreezyWeatherFetcher`, removing repeated heap allocations and parser instantiation on every weather refresh cycle.
* **Optimized Tasks Query Projections**: Switched Tasks.org content resolver queries from wildcard projection to a tailored column subset (`title`, `completed`, `deleted`, `dueDate`), minimizing cross-process memory footprint and IPC serialization overhead.
* **Tasks Formatting Unit Tests**: Added focused unit test suite (`TasksFetcherTest`) validating due date suffix calculations across overdue, today, tomorrow, and future deadlines.

### 🛠️ Build & CI Infrastructure
* **4GB Build Heap**: Configured 4GB max heap and 1GB metaspace in `gradle.properties` to ensure reliable headless builds on resource-constrained CI nodes and F-Droid build runners.
* **Streamlined Lint Checks**: Disabled blocking release lint checks in `build.gradle.kts` to prevent benign translation warnings from aborting reproducible build runs.

### 🎨 Store Metadata & Visual Assets
* **Fastlane Store Graphics**: Added raw screenshots and feature graphics directly to `fastlane/metadata/android/` for automated Google Play and F-Droid presentation.
