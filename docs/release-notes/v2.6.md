## 🚀 What's New in v2.6

### 🔍 Unified Global Settings Search
* **Search Everything**: Added a unified real-time search bar placed prominently above the live preview to instantly filter across all settings (Style, Content, Reorder, System).
* **Dynamic Tab Expansion**: Settings categories automatically expand during an active search for seamless discovery and cleanly restore once the search query is cleared.

### 📅 Calendar App Picker & Smart Permissions (Issue #55)
* **Custom Calendar Client**: Choose your preferred installed calendar app (Google Calendar, Proton Calendar, Simple Calendar, etc.) or launch system calendar events directly.
* **In-Widget Permission Prompts**: Tapping calendar or step count items when permissions are not yet granted now guides you directly to the relevant permission dialog.
* **Timezone & Query Boundary Fixes**: Resolved all-day event query boundaries and UTC timezone calculations for accurate upcoming event tracking.

### 🎨 Visual Contrast & Adaptive Preview
* **High-Contrast Category Tabs**: Redesigned category navigation tabs in Light Mode with bold primary indicators and crisp pill borders for immediate visual clarity.
* **Adaptive Preview Wallpaper**: Added dynamic light and dark wallpaper backdrops that sync seamlessly with active presets and theme modes.
* **Typographic Contrast Boost**: Upgraded light theme primary, secondary, date, and alarm text contrast to deep 900/800 tones.
* **Pixel-Perfect Alignment**: Aligned widget background fill and outline containers across all 11 font layout styles to prevent preview boundary collapses.

### ⚡ Modular Architecture & Performance
* **Single-Responsibility Architecture**: Modularized `AwidgetProvider` into focused components: `CalendarFetcher`, `SystemStatsFetcher`, `TasksFetcher`, and `WidgetRenderer`.
* **Lean Dependency Footprint**: Stripped unused `WorkManager` dependencies and legacy update workers, reducing APK size and background resource overhead.
* **Robustness Fixes**: Resolved midnight step count tracking glitches, guarded weather parsing against malformed network responses, corrected `bg_opacity` preference parsing, and restored the `font_style` preference key.
