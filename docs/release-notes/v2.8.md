## 🚀 What's New in v2.8

### 📅 Calendar 24-Hour Clock Synchronization (#97)
* **24-Hour Event Support**: Calendar events now dynamically synchronize with your widget time preferences and system clock format.
* **Accurate Evening Times**: Resolved Issue #97 where afternoon and evening events displayed in 12-hour format without AM/PM (e.g. `7:30`) even when the main widget clock was set to 24-hour format. Evening events now display clearly as `19:30`.
* **Consistent Multi-Day Formatting**: Fully supported across today, tomorrow, and near-future date abbreviations (`H:mm` and `EEE H:mm`).

### 🌍 World Clock Polish & Native Auto-Ticking
* **Native Battery-Free Auto-Ticking**: Upgraded the World Clock display to a native `TextClock` across all 11 widget font layout styles. The world clock now updates seamlessly every minute on your home screen with zero CPU wakeups or battery drain.
* **12h/24h Format Fix**: Fixed formatting logic so the World Clock correctly displays AM/PM indicators in 12-hour mode (`h:mm a`) and cleanly switches to 24-hour mode (`H:mm`) based on your configuration.
* **Independent Visibility**: Fixed container visibility logic so the World Clock remains visible even when the main date row is disabled.

### ⏱️ Screen Time Live Refresh
* **Routine Tick Updates**: Integrated Screen Time into periodic widget tick updates, ensuring your active daily screen usage stays current on the widget throughout the day.

### ⚡ Battery & Performance Refinements
* **Receiver & IPC Optimization**: Cached battery intent filters statically and added early exits when battery or temperature monitors are disabled, eliminating redundant system IPC calls.
* **Expanded Test Coverage**: Added comprehensive unit test suites covering World Clock timezone formatting, 12h/24h conversions, error resilience, and step delta calculations.

### 📦 Official F-Droid Inclusion Readiness (#73)
* **Metadata Recipe**: Added official F-Droid metadata recipe (`fdroid/com.leanbitlab.lwidget.yml`) ready for submission to the `fdroiddata` repository.
* **100% FOSS Verification**: Verified clean, reproducible release builds with full R8 optimization, resource shrinking, and zero proprietary dependencies.
