## 🚀 What's New in v2.5

### 🎨 Material 3 Polish & Iconography Overhaul
- **Brand New Iconography**: Pixel-perfect vector icons across all 20+ setting rows, custom color pickers, and categories.
- **Material 3 Pill Tabs**: Smooth elastic pill tab switcher with top icons and bottom labels.
- **Filled Pill Presets**: Clean Material 3 filled container selection chips for one-tap aesthetic presets.

### 📐 Resizing & Layout Precision
- **Square Resizing**: Full support for resizing the widget into compact 2x2 and square layouts on Android home screens.
- **Pixel-Perfect Outline**: Concentric, aligned outline and corner curves that seamlessly match the widget background.
- **No More Item Overlaps**: Precise typographical line-height stacking in the widget's right column across all 11 font styles.

### ⚡ Smooth Drag-and-Drop Reordering
- **High-Performance Drag**: 120fps fluid reordering with tactile haptics, lift animation, and enlarged grab handles.
- **Zero Scroll Conflicts**: Recursive parent touch locking prevents the settings scroll from interrupting reorder drags.

### ⚙️ System & Stability
- **Target SDK 36**: Built and optimized for Android 16 with full edge-to-edge system insets support.
- **Lightweight Performance**: Ultra-lean memory footprint (~7.8 MB heap) with zero memory leaks.
