## 🚀 What's New in v3.0

### 🎨 Material You & Widget Colors
* **Follows Wallpaper and Dark Mode**: Widget colors are now applied as color resources on Android 12+, so the launcher re-tints the widget automatically when you change your wallpaper or switch between light and dark mode.
* **Material Bolt Charging Icon**: The charging state is now shown with a Material bolt icon that is tinted with the widget text color, instead of a fixed-color glyph.

### 🐛 Fixes
* **Update Interval Changes Apply Immediately**: The periodic widget refresh is rescheduled when you change the update interval.
* **More Reliable Background Updates**: Broadcast work is now time-bounded, and number formatting uses an explicit locale for consistent output in every language.

### ⚡ Performance & Battery
* **Debounced Slider Updates**: Dragging a settings slider no longer triggers a widget re-render on every step, reducing IPC and battery use.

### 📱 Settings UI & Accessibility
* **Tablet and Landscape Layout**: Settings content width is capped on large screens for better readability.
* **Switch Haptics**: Toggles give haptic feedback.
* **Reorder Accessibility**: The reorder list offers move up/down actions for screen reader users, and decorative setup icons are hidden from TalkBack.

### 🌐 Localization
* **Fully Translatable UI**: Remaining hardcoded UI strings moved into resources, and the weather hint dialog is shared across screens.

### 🔒 Privacy & Build
* **Fewer Permissions**: Removed the unused `ALARM_LISTENER` permission.
* **Quality Gates**: New CI workflow runs unit tests, lint (fails on errors) and a string resource consistency check on every push and pull request, plus new smoke and unit tests for settings, preferences and update scheduling.
* **Cleaner Codebase**: `MainActivity` split into per-section files for easier maintenance.
