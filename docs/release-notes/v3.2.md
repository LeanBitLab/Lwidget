## Lwidget 3.2

### Added
* **Events and Tasks Together**: Both can now be on at once. A small arrow button at the bottom left flips between them with a vertical flip animation, Events first.

### Changed
* **Faster Settings**: The settings screen opens faster because tabs are inflated lazily. Cold start drops from about 3.2s to 2.3s.

### Fixed
* **Centered Icons**: Weather, steps and screen time icons are now vertically centered in all widget layouts (fixes #108).
* **Translated Setup and Settings**: The setup screen and a few settings views now use translated strings.

### Maintenance
* **Layout Text Check**: CI now checks layouts for hardcoded text.
* **Cleanup**: Shared battery optimization toggle, and `Log` is used instead of `printStackTrace`.
